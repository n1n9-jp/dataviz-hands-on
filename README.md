# データ可視化 体験教材

図を「読む側の知覚」と「作る側の選択」から理解するための、5つの小さな実験です。ブラウザだけで動き、ビルドは不要です。

公開ページ: https://n1n9-jp.github.io/dataviz-hands-on/

| 教材 | 内容 | リンク |
|---|---|---|
| 1 知覚の実験 | 長さ・角度・面積・濃淡などを見積もり、表し方ごとの自分の誤差を測る | [#perception](https://n1n9-jp.github.io/dataviz-hands-on/#perception) |
| 2 対応づけ | 東京の月別気温・降水量を、軸・色・大きさに割り当て直す | [#mapping](https://n1n9-jp.github.io/dataviz-hands-on/#mapping) |
| 3 ゆがみ | 棒グラフの基線、円の半径と面積、二軸の重ね方を動かす | [#distortion](https://n1n9-jp.github.io/dataviz-hands-on/#distortion) |
| 4 要約と図 | アンスコムの4つのデータ | [#summary](https://n1n9-jp.github.io/dataviz-hands-on/#summary) |
| 5 色 | データの種類と配色の組み合わせ、色覚の簡易シミュレーション | [#color](https://n1n9-jp.github.io/dataviz-hands-on/#color) |
| 授業で使うとき | 教員向けの進め方と問いかけの例 | [#guide](https://n1n9-jp.github.io/dataviz-hands-on/#guide) |

## 使い方

1. ページ上部のカードから教材を選びます
2. 各教材の最初にある番号つきの「手順」のとおりに操作します
3. 最後の「考えてみよう」で、気づいたことを言葉にします

## 注意

- 教材1は研究の課題を簡略化した体験版です。画面の色や大きさは較正していません
- 回答は保存されません。ページを再読み込みすると最初に戻ります
- 色覚のシミュレーションは色変換行列による近似です
